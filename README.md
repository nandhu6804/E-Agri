# E Agri

## Overview

E Agri is an agricultural ecommerce web application developed using the Django framework. The platform connects farmers and customers through an online marketplace, enabling easy buying and visiting of agricultural products.

## Roles and Functionalities

### Admin

* Manage users (farmers and customers)
* Add, update, and remove product categories
* Monitor products and orders
* Manage platform activities and reports
* Ensure system security and maintenance

### Farmer/User

* Register and log in to the platform
* Add, update, and delete products
* Manage product inventory
* View customer orders
* Track sales and order status

### Customer

* Register and log in to the platform
* Browse available products
* Search products by category
* Add products to cart
* Place orders
* View order history and status

## Installation

```bash
git clone <repository-url>
cd e-agri
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
